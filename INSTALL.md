# Quick Installation Guide

## Install the Extension

1. **Download/Clone** this repository to your computer
2. **Open Chrome** and go to `chrome://extensions/`
3. **Enable Developer Mode** (toggle in top right corner)
4. **Click "Load unpacked"** and select the `prompt-queue` folder
5. **Pin the extension** to your toolbar for easy access

## First Use

1. **Go to ChatGPT**: Navigate to [chat.openai.com](https://chat.openai.com) or [chatgpt.com](https://chatgpt.com)
2. **Click the extension icon** in your Chrome toolbar
3. **Add prompts** using the Manual or Matrix tabs
4. **Start the queue** from the Queue tab

## Test the Extension

1. **Manual Test**: Add a simple prompt like "Hello, how are you?" and test the queue
2. **Matrix Test**: Copy the contents of `test-matrix.txt` and paste it into the Matrix tab

## Troubleshooting

- **Extension not working?** Make sure you're on chat.openai.com or chatgpt.com
- **Icons missing?** The extension will work without icons, but you can create PNG files from `create_icons.html`
- **Permission errors?** Make sure you've enabled Developer Mode
